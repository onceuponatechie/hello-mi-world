# Before You Ship
## 20 checks before sharing a first version

By Essy Udeme · Tools & Templates

Open the work as a new visitor would. Follow the main task before working through this list. Check an item only after trying it; write N/A beside anything that does not apply. Keep unfinished items in the issue log below.

## Start with the person

- [ ] 01. A new visitor can tell what this is and who it is for.
- [ ] 02. The first screen names or shows the task the visitor can complete.
- [ ] 03. The main next action is visible, and its label describes what happens.
- [ ] 04. Terms unfamiliar to the intended visitor have been explained or replaced.
- [ ] 05. The copy describes what exists now and does not promise unfinished work.

## Try the interactions

- [ ] 06. Every link and button reaches the intended destination or action.
- [ ] 07. Forms accept a valid entry and explain missing or invalid entries. Use test data in a test environment.
- [ ] 08. The main task can be completed with a keyboard, with focus visible throughout.
- [ ] 09. A failed action tells the visitor what happened and how to try again.
- [ ] 10. Empty, loading and completed states give the visitor a next step.

## Read on another screen

- [ ] 11. At a narrow mobile width, the main task works without sideways page scrolling.
- [ ] 12. Text remains readable when zoomed, and important content is not clipped.
- [ ] 13. Images load, have appropriate alternative text, and do not hide important copy if they fail.
- [ ] 14. Scroll behaviour, menus and fixed elements do not block buttons or fields.
- [ ] 15. Reduced-motion preferences are respected, and motion does not prevent using the work.

## Prepare the handoff

- [ ] 16. Claims, quotations, calculations and source references have been checked against their originals.
- [ ] 17. A recipient can access the page or files with the permissions intended for them.
- [ ] 18. Downloads have descriptive names, open correctly, and contain the promised material.
- [ ] 19. A visitor or recipient knows where to send feedback or report an issue.
- [ ] 20. Someone owns the remaining fixes, with a date to check them again.
