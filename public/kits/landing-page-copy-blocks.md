# Landing Page Copy Blocks

By Essy Udeme — Why Not Build?  ·  whynotbuild

**Headline** — [outcome] for [specific person].

**Subhead** — how it works, in one sentence, no adjectives.

**Proof strip** — number, name, or screenshot. Not logos you borrowed.

**Three blocks** — each: one claim + one piece of evidence.

**Objection** — name the reason they'd say no, then answer it.

**Wrong fit** — "This isn't for you if ____." Honesty converts.

**Single CTA** — same words, every time it appears.
