# One-Thumb Mobile Test

By Essy Udeme — Why Not Build?  ·  whynotbuild

1. Stand up. Hold the phone in one hand.
2. Complete the main action with your thumb only.
3. Throttle to slow 3G. Do it again.
4. Reload mid-form. Is the typing still there?
5. Read every loading state aloud. Does it say what's happening?

Fail any step -> fix before anyone else sees the screen.
